# Historical container scripts

These files preserve the retired container setup and the earlier f(5)
single-cube script as source text. The `.sh.txt` extension distinguishes
them from maintained runnable tools. They contain historical machine paths,
branch names, and checkpoint commands, and are not current launch recipes.

Current entry points are the [campaign driver](../../../tools/campaign/cube_campaign.py)
and [order-5 certificate runner](../../../tools/verify_five_cubes.py).
See [campaign reference](../../reference/campaign.md) for supported usage.
