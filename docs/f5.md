# Order 5: f(5) = 16

The Lean theorem `f5_eq_16_of_unsat` combines a conditional upper bound
with an explicit witness of 16. Its only UNSAT hypothesis covers 120
Lean-defined cubes; all were externally checked by cake_lpr in the
recorded campaign. See the [ledger](results.md) for the trust boundary.

## Witness and verification

The [structured witness](../results/f5/witness-16.json) is the instance
`witnessI` in [ExactMaximum.lean](../lean/SmpMax/Five/ExactMaximum.lean).
From the repository root:

```bash
python3 tools/verify_witnesses.py results/f5/witness-16.json
```

Expected: `f5-16: 16 stable matchings; all three counts agree [OK]`.
The [standalone witness](../lean/checks/FiveWitness.lean) proves the count
using Lean's kernel and only `propext`.

For the upper bound, follow the [verification guide](verification.md):
build Lean, inspect the axioms, export the formulas, and run the checked
certificate pipeline. [Historical verification output](../results/f5/lean-cubes/verification.txt)
is retained for provenance; freshly checked certificates provide independent evidence.
