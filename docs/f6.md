# Order 6: f(6) = 48

The result combines a Lean schedule reduction, a completed SAT certificate
campaign, and an explicit lower-bound instance. **The complete Lean theorem
connecting an arbitrary counterexample to a satisfiable campaign cube is
still in progress.** See the [ledger](results.md) for the distinction.

## Witness and verification

The [dihedral witness](../results/f6/witness-48.json) has 48 stable matchings.
From the repository root:

```bash
python3 tools/verify_witnesses.py results/f6/witness-48.json
```

Expected: `f6-48: 48 stable matchings; all three counts agree [OK]`.

The completed campaign's [artifact directory](../results/f6/campaign-2026-09-08/README.md)
contains its journal and audit reports. The [verification guide](verification.md)
separates checking recorded coverage from generating and checking fresh certificates.
The earlier [general enumeration artifacts](../results/f6/enumeration/README.md)
provide an independent computational cross-check.
