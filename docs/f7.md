# Order 7: f(7) ≥ 85

Two explicit order-7 instances have 85 stable matchings. Each comes from a
size-2 schedule with 20 steps. This establishes a lower bound; the upper
bound remains open and these witnesses have no Lean proof object.

## Witnesses and verification

Use the [structured witnesses](../results/f7/witnesses-85.json), or inspect
the [original rank tables and schedules](../results/f7/witnesses-85.txt).
From the repository root:

```bash
python3 tools/verify_witnesses.py results/f7/witnesses-85.json
```

Expected: two successful rows, `f7-85-a` and `f7-85-b`, each with 85.
The verifier compares full matching sets from independent counters,
rotation-poset downsets, and the read-off preferences of each saved schedule.

## Search again

```bash
python3 -m experiments.search.search_swap_schedules 7 9 300
```

Arguments are order, random seed, and runtime in seconds. This performs
a new search; it is not required for witness verification. A timed search
is not guaranteed to rediscover a particular witness on every machine.

Schedule length is a search variable. Full-budget order-7 swap schedules
have 21 steps and the recorded experiments plateaued at 80; the saved
85-matching witnesses each use 20. Their structure motivates the
size-2/sub-budget conjectures described in the [research history](history/f7-search.md).

## Context and limits

The original comparison, checked on 2026-09-06, was with the 81-matching
instances in the [Ong et al. 2024 data](https://oeis.org/A357271/a357271_1.txt).
Confirm literature priority before making a new public record claim.

The order-6 certificate route scales poorly here: its order-7 depth-3 cube
count was sampled at approximately 3.25×10^8, with a much larger base
formula. That is an estimate from the recorded exploration, not an
exhaustive order-7 run. The current matching counters enumerate n!
permutations; larger orders need a more scalable counting method.
