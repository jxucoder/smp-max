# Order-7 witnesses

[witnesses-85.json](witnesses-85.json) contains the two preference-list
instances and their schedules. [witnesses-85.txt](witnesses-85.txt) preserves
the original one-based paired rank tables, discovery seeds, and dated
literature comparison unchanged.

The JSON uses best-first, zero-based lists; see the [format reference](../../docs/reference/formats.md).
Use [verify_witnesses.py](../../tools/verify_witnesses.py) to check the data
and the [order-7 guide](../../docs/f7.md) for the result's scope.

The `search/` directory preserves the later free-length and full-budget
search logs from upstream `5e8cb3c`; interpretation is in the
[order-7 guide](../../docs/f7.md).
